## Hardware
- **Primary Machine**: ThinkPad P1 Gen 6 (Intel i9, 64GB RAM, Ubuntu 24.04 LTS / Windows 11 dual boot)
- **Monitors**: Dual Dell UltraSharp 27" 4K USB-C Displays in calibrated sRGB
- **Keyboard**: Keychron Q1 Pro (Wireless Custom Mechanical, Banana Switches, lubed)
- **Audio**: Sennheiser HD 600 + Schiit Magni/Modi DAC stack

## Development Environment
- **Editor**: Neovim + VS Code with minimal telemetry extensions and strict vim bindings
- **Terminal**: Alacritty + Tmux with custom status bar showing git branch & CPU load
- **Shell**: Zsh with Starship prompt, `fzf` fuzzy finder, and `zoxide` directory jumper
- **Multiplexer**: Tmux with custom keybindings for instant session recall

## Infrastructure & Tooling
- **Containers**: Docker with Colima / Podman
- **Databases**: PostgreSQL, Redis, ClickHouse, SQLite
- **Observability**: Prometheus, Grafana, OpenTelemetry, Jaeger
- **Prototyping**: Go, Rust, TypeScript, Python for ad-hoc data transformations
